# Kenya Data Protection Act, 2019 — Sub-Processor & Cross-Border Transfer Register

**Document Version:** `2026-11-v4`  
**Statutory Scope:** Kenya Data Protection Act, 2019 (No. 24 of 2019), Sections 25, 29, 30, 32, 33, 41, and **48–50**, read alongside the ODPC *Guidance Note on Cross-Border Data Transfers* and *Guidance Note for Processing Children's Data*.

This operational register maps every infrastructure sub-processor and optional external network integration reachable from **Busherian Biasharas**, the personal or location data fields involved, the statutory cross-border transfer ground under Sections 48–49 of the Act, technical safeguards enforced in application code, and organizational governance items verified by the directory controller.

## 2. Hosting Backups & Operational Verification Checklist

Because source code cannot unilaterally inspect external hosting hypervisors or signed vendor contracts, the directory controller maintains the following operational verification checklist alongside each production environment:

1. **Hosting Sub-Processor & Backup Rotation Verification:**
   - Record the active legal entity, server datacenter country, and provider Data Processing Addendum (DPA) reference for `Angryhosting` in controller compliance files.
   - Verify the hosting provider's automated disaster-recovery backup retention window (typically 7–30 days rolling snapshots) so erased records age out of offline backups without manual restoration into production.
2. **SMTP Relay Transport Policy Verification:**
   - Keep `SMTP_ENCRYPTION=ssl` (port `465`) or `SMTP_ENCRYPTION=tls` (port `587`) and `ALLOW_PHP_MAIL_FALLBACK=no` / `SMTP_DISABLE_MAIL_FALLBACK=yes` in production `.env`.
   - Confirm the SMTP provider's outbound relay enforces opportunistic/mandatory TLS toward recipient mail servers and sign DKIM/SPF/DMARC for `busherianbiasharas.com`.
3. **Curated Listing Lawful-Basis Evidence:**
   - Whenever an administrator publishes an `admin_curated` listing, record the concrete authorization reference or public alumni chapter registry source in `admin_provenance_note`, and honor any pause/takedown objection immediately via `/takedown.php` or the admin console.
4. **Sensitive Personal Data Assessment (Kenya DPA s. 49):**
   - Busherian Biasharas prohibits children's data (`18+` adult-only gates across submission, claiming, first-time Google OAuth onboarding, and owner listing edits) and collects no health, biometric, ethnic, or political-opinion categories.
